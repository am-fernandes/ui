**`DateInput` ganha `size`.** `size` (`"sm"`, `"md"` ou `"lg"`, padrão `"md"`) dá a altura da caixa inteira, 32, 40 ou 44 px, a mesma de um botão, campo ou select do mesmo tamanho; o botão do calendário acompanha. Antes o gatilho tinha altura própria, que não alinhava com os outros controles.
