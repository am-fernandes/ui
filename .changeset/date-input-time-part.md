**`DateInput` mostra a data de um valor com hora.** Um `value` vindo da API como `"2025-03-14T00:00:00Z"` aparecia como campo vazio. Agora o campo mostra a parte da data (`14/03/2025`) e o calendário abre nela; o que o campo reporta continua sendo só a data (`"2025-03-14"`).
