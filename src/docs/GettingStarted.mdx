# @am-fernandes/ui

Design system oficial da AM Fernandes — 40+ componentes React acessíveis, theming em OKLCH, fonte Google Sans Flex, light-only.

## Pré-requisitos

- **Node ≥ 20** ou **Bun ≥ 1.1**
- **React 19**
- **Tailwind CSS v4**

## Instalação

1. **Configure o registro privado** (uma vez por máquina):

```bash
# ~/.npmrc
@am-fernandes:registry=https://npm.pkg.github.com
//npm.pkg.github.com/:_authToken=${GITHUB_TOKEN}
```

2. **Adicione o package:**

```bash
bun add @am-fernandes/ui
# ou
npm install @am-fernandes/ui
```

## Setup

No CSS de entrada da app:

```css
/* src/index.css ou app/globals.css */
@import "@am-fernandes/ui/fonts";
@import "@am-fernandes/ui/styles";
```

Pronto. Tokens, paleta e fonte ficam ativos globalmente.

## Primeiro componente

```tsx
import { Button, Typography } from "@am-fernandes/ui"

export function Demo() {
  return (
    <div className="space-y-4">
      <Typography variant="title">Olá, AM</Typography>
      <Button onClick={() => alert("Funcionou")}>Salvar</Button>
    </div>
  )
}
```

## Conceitos

- **Light only.** Sem dark mode por escolha de produto.
- **Tokens são a API.** Consuma cor/raio/espaço via classe Tailwind (`bg-primary`, `rounded-md`), nunca hardcoded.
- **Acessibilidade ≥ AA.** Componentes seguem padrões ARIA; status badges, contraste e foco validados.
- **Composição sobre configuração.** Componentes verbosos (Dialog/Sheet/Popover) ficam compositionais para máxima flexibilidade. Componentes onde uma API plana faz sentido (Breadcrumb, Tabs simples) também expõem `items`.

## Migração de apps existentes

Para apps internas que já usam cópias shadcn locais:

1. Adicione a dep + os imports CSS (passos acima).
2. Substitua um import por vez:
   ```diff
   - import { Button } from "@/components/ui/button"
   + import { Button } from "@am-fernandes/ui"
   ```
3. Para acelerar, use sed em uma página piloto antes de aplicar globalmente:
   ```bash
   find src -type f -name '*.tsx' -exec \
     sed -i 's|from "@/components/ui/\([a-z-]*\)"|from "@am-fernandes/ui"|g' {} +
   ```
4. Smoke-test a página, então delete `src/components/ui/*.tsx`.

**Gotchas conhecidas:**
- `Button` não tem mais flow de confirmação embutido — use `AlertDialog` quando precisar confirmar.
- Sem dark mode. Remova qualquer toggle de classe `.dark` que ainda exista.
- Helpers `toCents`, `fromCents`, `centsToDisplay`, `percentOfTotal`, `percentFromValue`, `formatBRL` são exportados — delete `lib/currency.ts` locais.

## FAQ

**Posso usar com Vite ou Next.js?** Sim. O package é ESM puro; qualquer bundler com React 19 + Tailwind v4 funciona.

**Posso adicionar variantes a um componente existente?** Use `className` (passa pelo `cn()` com tailwind-merge). Para variantes de marca, abra uma issue.
