# Colors

A paleta do grupo: **AM Fernandes** e **Ponto Forte** dividem o mesmo marinho (`#00355e`), e é dele que sai tudo. Os neutros são a escala **Grafite**, que tem o matiz do marinho e quase nenhuma saturação; a primária é o tom mais fundo da escala **Marinho**. As cores vivas dos brandbooks ficam na comunicação da marca e só voltam, dessaturadas, nos gráficos.

Os componentes usam **papéis** (`--background`, `--primary`, `--destructive`), nunca um degrau da escala. Os valores estão em `src/styles/tokens.css`, em `oklch(L C H)`.

## Dois temas

Cada token tem um valor no tema claro (`:root`) e outro no escuro (`.dark`), com o mesmo papel. As amostras desta página mostram o tema que estiver ligado; para trocar, abra qualquer story e use **Claro / Escuro** na barra de ferramentas.

`bun run audit:contrast` mede, nos dois temas, os pares que os componentes desenham (texto ≥ 4,5:1; anel de foco, borda do botão outline e marcas sólidas ≥ 3:1) e a distância entre as cores que precisam ser distinguidas quando se simula daltonismo. Falha se algum não passar. As regras de daltonismo estão em **Foundations / Color Vision**.

## Superfícies: dois fundos

`--background` é **a página**: só a área de conteúdo, um tom abaixo das superfícies. Tudo que é peça (card, tabela, campo, botão outline, aba ativa, menu lateral, navbar) pinta `--card` ou `--sidebar`. O que flutua (menu, popover, dialog) pinta `--popover`. A distância entre página e superfície é mínima de propósito (1,05:1 no claro, 1,08:1 no escuro): quem separa as camadas é a borda.

## Status

**Um fundo forte para cada status, nunca uma versão de fundo claro.** O texto sobre ele é o `-foreground` do token: branco em erro, sucesso e informação; escuro no alerta, porque branco sobre ouro não chega a 4,5:1 sem virar marrom.

Cada status tem a sua luminosidade, e o verde puxa para o azul. Assim nenhum par depende só do eixo vermelho-verde, que 1 em cada 12 homens não distingue bem (veja **Foundations / Color Vision**).

## Categóricas

Nove cores para categorizar sem significado de status: chips do `Token` e eventos do `Schedule`. Cada uma tem um fundo (`-bg`), um texto (`-text`, 8:1 ou mais sobre o fundo) e um tom sólido (`-solid`, 3:1 ou mais sobre a superfície). O croma é baixo e **cada sólido tem a sua luminosidade**: é o ponto ou a barra sólida, junto do rótulo, que identifica a categoria. Fundo e texto são apoio.

export const Category = ({ name }) => (
  <span

    }}
  >
    <span style={{ width: 8, height: 8, borderRadius: 9999, background: `var(--category-${name}-solid)` }} />

## Gráficos

`BarChart`, `LineChart` e `Sparkline` já usam estas cores; para outro tipo de gráfico, use os tokens. São três paletas, uma para cada pergunta:

export const Series = ({ vars }) => (
  <div style={{ display: "flex", height: 36, borderRadius: "var(--radius-inner)", overflow: "hidden", margin: "8px 0 4px" }}>
    {vars.map((v) => (
      <span key={v} style={{ flex: 1, background: `var(${v})` }} />
    ))}
  </div>
)

**Categórica: quem é quem.** `--chart-1` a `--chart-6`, sempre nesta ordem: azul, terracota, ameixa, oliva, rosa, petróleo. Vizinhas diferem em luminosidade. Passou de seis séries, agrupe o resto em "Outros". Onde qualquer par pode se encostar (dispersão, mapa), use só as três primeiras.

<Series vars={["--chart-1", "--chart-2", "--chart-3", "--chart-4", "--chart-5", "--chart-6"]} />

**Sequencial: quanto.** `--chart-seq-1` a `--chart-seq-5`, um matiz só. No claro, o tom claro é "pouco"; no escuro inverte.

<Series vars={["--chart-seq-1", "--chart-seq-2", "--chart-seq-3", "--chart-seq-4", "--chart-seq-5"]} />

**Divergente: abaixo e acima de um centro.** `--chart-div-1` a `--chart-div-7`: vermelho, um meio neutro (`--chart-div-4`) e marinho, com os dois braços na mesma luminosidade.

<Series vars={["--chart-div-1", "--chart-div-2", "--chart-div-3", "--chart-div-4", "--chart-div-5", "--chart-div-6", "--chart-div-7"]} />

Nenhuma série repete uma cor de status, e todo gráfico leva legenda: a cor nunca é a única pista.
