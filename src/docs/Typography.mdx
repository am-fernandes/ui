# Typography

A AM Fernandes adota **Google Sans Flex** como fonte oficial — uma variable font otimizada para interfaces, com escala fluida de tamanhos (`opsz 6–144`) e pesos (`wght 1–1000`).

## Por que Google Sans Flex?

| Critério | Google Sans Flex | Inter | Roboto | Nunito Sans |
|---|---|---|---|---|
| Variable font | ✅ opsz + wght fluidos | ✅ apenas wght | ❌ pesos discretos | ✅ apenas wght |
| Optical sizing (opsz) | ✅ corpos pequenos legíveis sem reflow | ❌ | ❌ | ❌ |
| Latin Extended (pt-BR) | ✅ | ✅ | ✅ | ✅ |
| Métricas otimizadas para UI | ✅ desenhada pelo Google Material UX | ⚠️ aceitável | ⚠️ datada (2011) | ⚠️ display-oriented |
| Peso final no bundle | 1 arquivo variável | 1 arquivo | 5+ arquivos | 2+ arquivos |

**Conclusão:** Roboto e Nunito Sans foram desenhadas antes do amadurecimento das variable fonts (overhead em rede e cache). Inter é tecnicamente competente mas não tem optical sizing — textos pequenos parecem "apertados". Google Sans Flex resolve ambos.

Disponível via `--font-sans` (CSS) e na classe Tailwind `font-sans`.

## Variantes

O componente `Typography` é a API recomendada — cinco variantes que cobrem a hierarquia editorial padrão de uma app:

<div style={{ display: "flex", flexDirection: "column", gap: 24, padding: 16 }}>
  <div>
    <div style={{ fontSize: 11, color: "var(--muted-foreground)", textTransform: "uppercase", letterSpacing: 1, marginBottom: 4 }}>
      display · text-4xl · font-bold · h1
    </div>
    <Typography variant="display">A AM Fernandes constrói software jurídico.</Typography>
  </div>
  <div>
    <div style={{ fontSize: 11, color: "var(--muted-foreground)", textTransform: "uppercase", letterSpacing: 1, marginBottom: 4 }}>
      title · text-2xl · font-semibold · h2
    </div>
    <Typography variant="title">A AM Fernandes constrói software jurídico.</Typography>
  </div>
  <div>
    <div style={{ fontSize: 11, color: "var(--muted-foreground)", textTransform: "uppercase", letterSpacing: 1, marginBottom: 4 }}>
      subtitle · text-lg · font-medium · h3
    </div>
    <Typography variant="subtitle">A AM Fernandes constrói software jurídico.</Typography>
  </div>
  <div>
    <div style={{ fontSize: 11, color: "var(--muted-foreground)", textTransform: "uppercase", letterSpacing: 1, marginBottom: 4 }}>
      body · text-sm · regular · p
    </div>
    <Typography variant="body">A AM Fernandes constrói software jurídico.</Typography>
  </div>
  <div>
    <div style={{ fontSize: 11, color: "var(--muted-foreground)", textTransform: "uppercase", letterSpacing: 1, marginBottom: 4 }}>
      caption · text-xs · muted · span
    </div>
    <Typography variant="caption">A AM Fernandes constrói software jurídico.</Typography>
  </div>
</div>

## Uso

```tsx
import { Typography } from "@am-fernandes/ui"

<Typography variant="display">Página de contratos</Typography>
<Typography variant="title">Filtros aplicados</Typography>
<Typography variant="body">Conteúdo paginado.</Typography>
<Typography variant="caption">Atualizado em 17/05/2026</Typography>
```

Cada variante mapeia para um elemento semântico padrão (display→h1, title→h2, subtitle→h3, body→p, caption→span). Use o prop `as` quando o outline do documento exigir um nível diferente.
